# React & JS Skills Showcase

REACT TASKS

1. Build a Counter App with Increment, Decrement and Reset functionality.

2. Build a Todo App with Add, Edit, Delete and Complete functionality.

3. Create a Product Search page with Search, Category Filter and Price Sorting.

4. Create a Registration Form with Name, Email, Phone, Password and Confirm Password validation.

5. Create reusable React components for Button, Input, Card and Modal.

6. Build an FAQ Accordion with Expand and Collapse functionality.

7. Fetch user data from a REST API and display Loading, Error and Empty states.

JAVASCRIPT TASKS

8. Reverse a string without using reverse().

9. Find duplicate values from an array.

10. Find the second-largest number from an array.

11. Count the frequency of each character in a string.

12. Remove duplicate values while preserving the original order.

13. Implement your own map() function.

14. Implement your own filter() function.

20. FINAL PROJECT:

    Build a basic Employee Management System with:

- Add Employee

- Delete Employee

- Search Employee

- Filter Employee
